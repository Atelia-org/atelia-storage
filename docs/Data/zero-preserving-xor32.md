# 保留零的 32bit 带 key 置换

`Atelia.Data.ZeroPreservingXor32.Apply(uint value, uint key)` 用于把局部整数编号编码成紧凑 Handle。相同函数用于正向与逆向：

```text
P_k(x) = x        当 x = 0 或 x = k
         x XOR k  其他情况
```

函数不分配状态，不要求 key 非零，不包含编号范围或文件存在性策略。它不是加密、MAC 或独立的库身份验证；相同 key 不同库完全不能区分，错 key 也可能解出另一个有效编号。调用者负责持久保存或稳定派生 key、检查范围、确认对应对象存在并执行其完整性检查。已经保存编码值时，不能无迁移地替换此位映射。

## 自逆与零

普通 XOR 会交换 0 与 k。本算法只把这个交换改为两个固定点；其余 XOR 交换保持原样。因此对所有 uint 输入及 key，`P_k(P_k(x)) = x`，零固定，非零域仍是完整的双射。key=0 时是恒等映射；key 可以等于有效编号而不丢失该编号。无需从分配器跳过任何编号。

## 低编号分组隔离

对于任意 `1 <= x < 2^b`，有：

```text
P_k(x) >> b = k >> b
```

普通分支由 XOR 直接得到；特殊分支 x=k 要求 k 自身也在低区间，因此双方高位仍都为零。于是，若两个 key 在高 `32-b` 位不同，它们对整个低编号区间的编码像严格不交。一个库的任意低编号 Handle 在另一个库解码后，都不在该低编号区间。

采用 b=24 的调用者可独立检查 `1 <= decoded <= 0x00ffffff`，容量为 16,777,215 个非零编号。对独立均匀随机的两个 32bit key，高 8 位不同的概率为 255/256；这些 key 对的所有合法 Handle 都能在范围检查处被拒绝。其余 key 对没有这一保证。固定 key 对没有运行时随机性，不能把这个概率当作每次操作独立失败率。

对于通常很小的连续编号集合，可以取更小的 b 分析整组分离。不同 key 只差最低一位时，绝大多数低编号会映到相邻编号，形成集中漏检。这是明确接受的代价：尽量让大多数错误库对整组拒绝，少量库对可能集中误命中。充分打散会改变集中方式，不能免费增加 Handle 携带的信息。

## 单次平均命中计数

固定非零编码值 h，令解码 key 在全部 `Q=2^32` 个值中均匀随机：

- key=0 与 key=h 都输出 h，共 2 次。
- 每个其他非零结果 y 对应唯一 key=`h XOR y`，各 1 次。
- 零永不输出。

因此，对任何包含 N 个非零编号的有效集合 S：

```text
Pr[P_key(h) in S] = (N + indicator(h in S)) / Q <= (N+1)/Q
```

这是固定 h 与随机 key 的计数，不是对任意指定错误 key 的保证；也没有条件化排除相同 key。对于完整非零 24bit 区间，N=2^24-1，所得上界恰为 1/256。不能将其简写为严格的 N/2^32，也不能再把 CRC、ticket 等验证作为独立随机事件连乘。

## 候选取舍与边界

- 加法平移同样便宜，但低编号映射成模空间中的连续区间，会出现进位和边界重叠；XOR 对二进制容量边界有直接的高位分组证明。
- 奇数乘法模 2^32 可逆并自然固定零，但保留输入的 2-adic 阶数，只有 31bit 奇数乘数，且缺少上述简单分组性质；本用途没有需要它解决的问题。
- Feistel 等充分打散的置换可减少某些 key 对的集中漏检，增加算法和持久规范成本。本合同不要求这项性质。

每个库 N 个合法编号需要 N 个互异编码值。要让所有不同库的合法像两两不交，在非零 32bit 空间最多容纳 `floor((2^32-1)/N)` 个这种集合。独立生成大量库且不协调分配时，无法保证任意不同 key 都把全部低编号解成大数。保留完整低频库身份与概率性紧凑 Handle 检查属于不同职责。

## 验证范围

`ZeroPreservingXor32Tests` 固定数值向量约束准确位映射；8bit 子域穷举验证双射、自逆、零保留、精确输出直方图及低编号分组；32bit 极值和 key 对反例验证分组与集中漏检边界。数学保证来自上述推导，缩小域穷举用于检测实现偏离，不能代替一般证明。

独立的 [CompactHandleProbe](../../experiments/CompactHandleProbe/README.md) 提供 Python 复算入口：用整张置换表及反表比较 XOR、加法和本构造的不同 key 对合法集合重叠分布，并输出确定性 JSON。该探针的不同 key 对均值已排除同 key，统计条件与上面的固定 h、全部随机 key 计数不同；32bit 部分仅为参考向量和采样，不替代生产程序集测试或全域证明。
